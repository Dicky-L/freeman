# A股启动雷达：五年历史回测

研究区间：2021-10-09 至 2026-10-09，额外使用2021年4月开始的预热行情。沪深主板 + 创业板，排除科创板及北交所。

## 当前范围
V0仅测试【初次放量→1日缩量回踩→二次放量突破】。
信号发生于T日收盘；T+1日开盘价格作为入场参考，五日/十日后收盘离场；估算往返综合交易成本0.18%。

## 使用
仓库工作流 `A-share five year study` 默认在 PR 触发全量八分片云端运行。
每片独立下载AKShare真实数据，失败不生成虚构收益。汇总Artifacts中有事件、汇总和数据缺失统计。

## 不能忽略
当前版本未完整处理历史退市/ST、历史涨跌停成交、除权除息调整、IPO涨跌幅规则、历史板块及点时财务公告，因此**不是最终五年量化验证，更不能认为策略已有统计显著性**。不要将事件触及+3%当作实际成交收益。
